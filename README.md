# Churrascaría GM

Sitio oficial preparado para **https://churrascariagm.com/** y despliegue estático en GitHub + Vercel.

## Publicación
1. Sube todos los archivos de esta carpeta a la raíz del repositorio de GitHub.
2. Importa el repositorio en Vercel como proyecto estático.
3. Agrega `churrascariagm.com` y `www.churrascariagm.com` en **Settings → Domains** de Vercel y configura los DNS que Vercel indique.
4. Una vez que el dominio responda por HTTPS, abre Google Search Console y valida la propiedad. El meta de verificación ya está integrado en `index.html`.
5. Envía `https://churrascariagm.com/sitemap.xml` en Search Console y solicita indexación de `https://churrascariagm.com/`.
